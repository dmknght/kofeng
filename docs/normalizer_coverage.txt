NORMALISER COVERAGE
===================

What this is: the normaliser - executables.c (the decode passes and the transform), script_norm.c and
script_fold.c (the form and the fold of a script), scan_norm.c / scan_norm_text.c / scan_norm_syms.c (the
view and its maps), objsrc.c and objprod.c (what a view declares and inherits), offmap.c and funcs.c
(carrying a description and the functions through the transform) - and which test pins each part.

How it was made (scratch scripts, nothing of them is in the tree):
  1. the ten sources were compiled with --coverage -O0 and linked IN FRONT of libkofeng.a / libkgenome.a,
     so each test ran the instrumented copy and nothing else changed;
  2. every test that links against libkofeng.a (tests/unit: 115 programs) or libkgenome.a (tests/lib/genome:
     51) was run, once together (the "before" column; the eight normalizer_* files are NOT among them) and
     once each in its own gcda directory (the "tests" column). Not linked: twelve tests of tests/unit that need
     extra sources (cond_expr, codec_forms, draft_source, fidset, fnprint_gcc, fridge, grille_host, kofscfind,
     out_clip, proc_rule, report_model, rule_roundtrip) and the platform tests (antarc_*, msf_xor,
     ko_anomalies, chan_ring, hostile_mem, reg_event, thread_region); none is about the normaliser.
  3. the eight new files were then added to the first run (the "after" column);
  4. the behaviour table (section 3) was written by reading each existing test and grepping tests/ for
     the function and the case; a behaviour no existing test states is marked UNTESTED.
