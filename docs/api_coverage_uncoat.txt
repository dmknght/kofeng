API COVERAGE OF libuncoat (the public umbrella <uncoat.h> and the headers it lists)
====================================================================================================

How this list was made: tools-free enumeration of every public name the headers listed in
libuncoat/uncoat.h declare (functions, macros, enumerators and enum tags, struct tags, function-pointer
typedefs, the one extern table), comments stripped; then a word search of tests/lib/uncoat/ and
tests/unit/ for each name. A reference is a reference, not proof of depth: the third column marks a
name whose only references are the smoke/fuzz/silent-loss files (surface.c, decomp_fuzz.c, stream_fuzz.c,
silent_loss_uncoat.c) as SMOKE-ONLY. The last column is the test file(s) this work added.
Private headers (rarcommon.h, inbyte.h, transform_private.h) are not public and are not listed.
