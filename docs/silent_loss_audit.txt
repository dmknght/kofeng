SILENT EVIDENCE LOSS AUDIT
==========================
Invariant (CLAUDE.md section 12): a limit exists only to bound DoS/size and must REPORT when hit
(kgenome/kuncoat status != OK, broken=LIMIT, kof_scan_incomplete, a flag or counter). It may never
make a smaller or empty result look complete. Every limit is listed with: LIMIT | location | class |
test | status.
  class a  reports when hit (signal cited)      class b  silently drops evidence (candidate loss)
  class c  not evidence (cannot lose a detection)
  status   REPORTS / PASS (test asserts the invariant) / KNOWN-MISS (KM_CHECK, cap string = limit) /
           UNTESTED (reason) / NOT-EVIDENCE.
A KNOWN-MISS turns into FIXED-UNEXPECTEDLY (red) the day the limit is fixed: change it to CK and
update its row. When a limit is added or changed, record it here. Severity words are [Inference].
Rows were enumerated by grep over libgenome, libuncoat, libkofeng and classified by reading the code.
